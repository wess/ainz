Tutorial 2 · your terminal

Make the harness fit the way you work.

Use the built-in designers for appearance, settings for durable preferences, and Lua for behavior that belongs only to your setup.

01

Set durable preferences

/settings
/statusline
/vim

Settings groups provider, interface, session, key, and memory choices. Changes made there are saved to config.toml. /statusline chooses and orders the built-in fields; /vim switches prompt editing modes.

02

Build a theme

Open the Theme Designer, tune each semantic role against the live transcript preview, and copy its install command. Back in Ainz:

/themes
/theme NAME

Themes are plain TOML. Ainz discovers a newly installed file without restarting, and reports malformed roles in /themes.

03

Draw a masthead

Use Masthead Studio for ANSI text or half-block pixel art. Install the result globally or in the current project, then select it:

/headers
/header NAME

Headers and themes stay separate, so palette changes do not recolor ANSI artwork that deliberately chose its own colors.

04

Create an init.lua

Put init.lua beside config.toml. On macOS that is normally ~/Library/Application Support/ainz/; on Linux it is ~/.config/ainz/.

ainz.opt.ui.vim = true
ainz.opt.max_steps = 48

ainz.keymap.set("ctrl+g", "/goal continue", { desc = "continue goal" })

ainz.command("review", function(e)
  ainz.send("Review the current changes. " .. e.args)
end, { desc = "review this checkout" })

Run /source after editing. ainz --clean starts without scripts when you need to isolate a configuration problem.

05

Shape the live screen

ainz.statusbar.item("clock", function()
  return "%Y" .. os.date("%H:%M") .. "%n"
end)
ainz.statusbar.set({ "clock", "model", "mode", "context" })

local log = ainz.panel.open({ side = "right", title = "tools", follow = true })
ainz.on("tool_start", function(call) log:append(call.name) end)

Status items and panels update from the running session. The color codes are the same irssi-style codes used throughout Ainz.

06

Share project configuration safely

A repository may include .ainz/init.lua. It does not execute merely because the project was cloned.

/trust
/source

/trust records the script's current content. Any edit makes it untrusted again. Keep personal configuration in the user config directory and commit only behavior the whole project needs.
