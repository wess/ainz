First connection

From zero to first run.

Install AgentX, choose the engine you already use, and learn the handful of controls that matter.

01

Install the binary

On macOS or Linux with Homebrew:

brew install wess/packages/agentx

Or with the verified installer:

curl --proto '=https' --tlsv1.2 -LsSf \
  https://raw.githubusercontent.com/wess/agentx/main/install.sh | sh

The installer selects your architecture, verifies its SHA-256 checksum, and writes to ~/.local/bin. Set AGENTX_INSTALL_DIR to choose another directory.

02

Open setup

agentx

With no model configured, AgentX opens setup inside the TUI. Add a provider, pick a model, and save. You can return at any time with /config.

03

Choose a provider

Ollama

agentx providers add ollama --preset ollama
agentx models list ollama --refresh
agentx providers use ollama qwen3:8b

Codex process

agentx providers add codex --preset codex --known-model gpt-5.6-sol
agentx providers use codex gpt-5.6-sol

Claude Code process

agentx providers add claude --preset claude-code --known-model sonnet
agentx providers use claude sonnet

Process providers use your existing authenticated CLI. AgentX does not need a separate Claude API key for the Claude Code preset.

04

Run a task

agentx ask "inspect this project and explain its architecture"

Or stay in the full-screen interface:

agentx

Type / for fuzzy command search. Ctrl+L toggles the remembered agent roster; Ctrl+1 selects the main session, Ctrl+2..9 select subagents, and Ctrl+=/- cycle (or /agent N in terminals without the kitty keyboard protocol).

05

Resume and branch

agentx sessions
agentx resume
agentx resume SESSION_ID --at NODE_ID "try the smaller fix"

Sessions are tree-structured. Resuming at an earlier node creates another path without erasing what came after it.

06

Connect Synapse

agentx mcp add synapse --required -- /absolute/path/to/synapse mcp

AgentX also accepts an ephemeral MCP launch profile with --mcp-config, so Synapse can start it with a mesh-specific tool configuration.
