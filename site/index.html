One harness. Every workflow.

01

Bring your model

Use Ollama locally, authenticated coding CLIs in headless mode, OpenAI-compatible endpoints, or your own process adapter.

02

Keep the context

Resume branching sessions, preserve token totals, compact long histories, and steer a run at safe turn boundaries.

03

Multiply yourself

Delegate durable subagent runs and switch among their transcripts without leaving the main terminal.

04

Extend carefully

Add MCP servers, skills, prompts, and capability-scoped plugins with content-pinned approval.

05

Work your way

Interactive TUI, one-shot prompts, JSON event streams, and persistent JSON-RPC all share the same engine.

06

Connect the mesh

Use Ainz with Synapse for cross-session memory and coordinated agent teams.
