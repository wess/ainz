A small file you can keep editing.
The installer writes one TOML file, refuses to overwrite an existing theme, and downloads nothing. Share the file, edit its colors, and run /theme NAME to reload it. Everything you draw or change stays in your browser until you copy or download it.
Themes color the chat interface, including its roster, prompt, and dialogs. Setup screens and message formats keep their existing layout. Already-flushed inline scrollback keeps its earlier colors. The importer accepts the flat [colors] table exported here.
Use a build with /theme support. If the command is missing, see installation options. Read the theme guide for paths, roles, and manual installation.
