Masthead studio

Paint your own masthead.

Every pixel is half a terminal cell. Save the result as an .ans file, drop it in .ainz/headers/, and Ainz renders it on the empty transcript exactly as the preview shows.

Left button paints with the selected tool, right button erases. Text places the typed word at the click. The magenta line marks 72 columns, the widest masthead that still fits beside the agent roster.

Preview

Install

The file is ordinary ANSI art: one half-block character per terminal cell, coloured with truecolor SGR. Other ANSI editors and less -R open it, and this studio reopens any half-block art, including files it did not write. The format and its limits are described in docs/headers.md. Work in progress stays in this browser until you clear it.
