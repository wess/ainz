Header guide

Just want the mascot? Run /header mascot in Ainz. To make your own, start here. Your drawing stays in this browser.

1. Draw your header

Loading drawing…

Drag to paint; right-click to erase. For text, choose Text and click to place it. Keyboard: focus the canvas, move with arrows, and press Space to draw.

Two pixel rows become one terminal row. Resizing crops or adds canvas; it never shrinks the drawing. Undo restores cropped pixels.

2. Check the preview

#main · your header

3. Add it to Ainz

This becomes the filename and your /header command.

Paste it into your shell. It writes this drawing directly; no download or file moving needed. Existing headers are kept.

Inspect the install command

          
Then, inside Ainz:
/header myainz

          
The header previews immediately. Any key returns to your conversation.

A header you can keep.
The export is ordinary ANSI art. Share the .ans file, reopen it here to add to it, or use it in another terminal art editor. The canvas accepts half-block pixel artwork; plain ASCII headers still work in Ainz itself. Read about formats, sizes, and manual installation.
Custom headers change the artwork. Use the Theme Designer for buffer colors. Message layout stays the same.
